# Mesa de rol (VTT ligero)

Frontend puro (HTML/CSS/JS ES Modules) + Firebase (Auth anónimo + Firestore) en GitHub Pages.

## Probar en local
VS Code → Live Server → "Go Live". Abre `http://127.0.0.1:5500/`.
Usa una ventana normal (Loremaster) y una de incógnito (jugador).

## Reglas de Firestore
Copia `firestore.rules` en Firebase → Firestore → Reglas → Publicar.
